# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-11-03

### Added

- Initial release with core CLI functionality
- `list` command to discover available tools
- `run` command with hot-reload support
- `inspect` command for socket monitoring
- Full TypeScript implementation with Jest tests
- GitHub Actions CI/CD pipeline
- MIT License

### Features

- Tool registry system
- File watching integration
- Port inspection capabilities
- Commander.js-based CLI
- >80% test coverage
